## CP ledger: confirmed arithmetic, not automatic repair

- Reference allocation: race 25 + Druid 100 + Ranger 60 + NWP 8 + weapon 8 + **one** shared INT allowance 2 = **203**. Reference advancement under the user's chosen 4 CP per class advance: (10−1 + 8−1) × 4 = **64**. Total **267**, not **269**; 269 counts INT 2 twice. These are restricted/category allocations, not an unrestricted NWP pool (S1/E).
- Do **not** change base allocations, advancement rate, multiclass advancement treatment, carryover, saved balances or spent counters automatically. The allocation comparison is conditional on the stated reference, not a new campaign rule.
- User-reported itemized improvements total **57, not 55**. With stated initial **28**, subtotal is **85, not 83**. Confirm whether 28 contains any trait/free-grant/crossover costs before using it as a ledger category.
- A claimed **6 CP discrepancy** cannot be established or explained from these aggregates. The two 2-point arithmetic corrections are not proof of a six-point overcharge, and total allocations minus this NWP subtotal is not a valid remaining balance.
- Recovery differs: Druid 11/Ranger 8, historical improvement map totals **81**, saved purchase components total **26**, NWP counter **107**, weapon counter **14**, unspent **4**. Historical target strings include the earlier formatter defect. These are historical evidence, not the latest 57/28 ledger or proof of legitimate expenditure (E).
- Needed complete ledger: matching character/version/levels and XP, race/class ability purchases, spheres and other configuration costs, carryover, disadvantages, trait costs, weapons, restricted INT distribution, each initial NWP purchase/free grant/crossover, every paid improvement by level, authorized exceptions, prior unspent CP and transactions.
