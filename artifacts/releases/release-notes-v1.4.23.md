## DMCortex 1.4.23

This release adds explicit spell selection to character export and completes the versioned Codex/Foundry character exchange.

### Highlights

- Choose exactly which eligible spells are included when exporting a character.
- Search and filter export candidates by spell name, category, and level.
- Prepared, cast, and spellbook spells remain automatically included.
- Priest sphere access no longer adds every available catalog spell to the character.
- Complete spell definitions, preparation counts, slot state, and casting pools round-trip by stable ID.
- Native and legacy equipment populate structured exchange records.
- Structured abilities now include display names and categories.
- Full Foundry source data and unknown nested properties remain lossless across round trips.
- Multiclass saving throws use each class's individual level.
